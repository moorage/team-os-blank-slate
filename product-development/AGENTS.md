# Product Development Instructions

This folder stores durable product context linked from Team OS cards.

## Rules

1. Keep artifact docs focused on durable context, not current workflow state.
2. Update `feature-index.yaml` when adding or changing important linked artifacts.
3. Prefer repo-relative links back to `kanban/cards/**/card.md`.
4. Use the nearest subfolder `AGENTS.md` when adding deeper docs.
